# Church Scheduler

Sistema para geração de escalas (rodízios) de voluntários para igrejas.

## Objetivo

Gerar automaticamente escalas considerando eventos, funções e regras de distribuição.

## Tecnologias

- Python
- Git
- Excel
- PDF
